# 🧠 AI Text Models Project

This project demonstrates how to build, test, and deploy various **AI-based text processing applications** using **Hugging Face Transformers**, **Gradio**, and **VS Code**.

---

## 🚀 Features
- Sentiment analysis demo using Hugging Face pipeline  
- Text summarization and generation capabilities  
- Gradio web interface for interactive demos  
- Clean modular Python project structure  
- Easy deployment to **Hugging Face Spaces**
